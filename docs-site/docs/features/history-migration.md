# 历史与迁移

## 联合历史

图谱历史不仅保存节点和关系，还会保存当时的文档快照。还原后，文档、图谱和引用数据一起刷新，避免旧图谱指向新文本或旧文本缺少对应节点。

文档编辑、增量更新和图谱编辑都可以进入这套回溯链路。

## 导出迁移包

对已完成文件执行“导出迁移包”，系统会生成 `.kmn.zip`，其中包含：

- 原始文档
- 转换后的文本
- 图谱主页与社区详情页
- 处理状态与检查点信息
- 与当前文件相关的 RAG 数据

## 恢复到另一实例

把 `.kmn.zip` 拖入另一套 KnowledgeMapNotes 的上传区。系统校验包内容后恢复数据，不重新调用文本模型。

迁移包上传大小上限为 `100 MB`。没有配置 AI 时也能导入，但导入后的新 RAG 问答仍需要模型。

## 完整备份

除了逐文件迁移，也可以整体备份这些关联目录：

```text
backend/uploads
backend/txt_files
backend/results
backend/chroma_data
backend/processing_states
backend/graph_history
```

整体恢复时应保持这些目录来自同一时间点，以维持原文、向量数据和图谱的一致性。
