# 生产环境与安全

KnowledgeMapNotes 当前没有内置用户登录或 API 鉴权，不应把后端端口直接暴露在不受信任的公网。

## 网络边界

- 仅本机使用时设置 `HOST=127.0.0.1`。
- 局域网或公网部署时，通过带身份验证和 HTTPS 的反向代理访问。
- 防火墙只开放反向代理端口，不直接开放 `8000`。
- 把 `CORS_ALLOW_ORIGINS` 限制为实际前端来源。

```dotenv
CORS_ALLOW_ORIGINS=https://notes.example.com
```

多个来源使用逗号分隔。公网环境不要保留 `*`。

## 密钥管理

- 不要把带真实密钥的 `backend/.env` 提交到版本库。
- 生产部署优先使用容器密钥、受控环境变量或操作系统权限保护配置文件。
- AI 连通性测试只发送固定的最小消息，不发送已上传文档。

## 数据保护

`uploads`、`txt_files`、`results` 与 `chroma_data` 包含用户内容或其派生数据。应统一设置访问权限、备份周期和保留策略。

如果知识库包含敏感资料，还应确认所用模型 API 的数据留存政策。即使应用本地部署，实体抽取和问答仍可能把必要上下文发送给远程模型服务。
