# 路线图

KnowledgeMapNotes 的方向是让知识图谱从一次性生成结果，变成可以持续学习、共享和协作的知识基础设施。以下计划会随着实际开发调整。

## 进行中

### 图谱习惯化学习

对比模型生成的初始图谱与用户剪枝后的图谱，学习用户的实体和关系偏好，帮助后续处理自动减少不必要的节点与关系。

### 文件图谱市场

建立可分享的文档图谱迁移包，让用户能够发布、发现并导入已经完成处理的知识图谱。

### 多端应用

在保持本地数据边界的前提下，完善桌面、局域网与移动端使用体验。

## 计划中

- 当本地知识图谱无法回答时，按需联网补充相关知识。
- 优化文本分块和向量 / 三元组融合策略。
- 增加笔记事实检查、复习试卷和讲解视频生成能力。
- 完善隐私数据脱敏与还原流程。
- 为问答 AI 增加 skill 等常用工具能力。
- 完善多模态模型在 PDF 与图像内容中的使用。

## 当前版本已具备

- TXT、Markdown、PDF 与 `.kmn.zip` 迁移包工作流
- 断点处理、失败接管、增量更新和联合历史回溯
- 图谱社区分页、关系权重、证据高亮与可编辑工作区
- 流式 HybridRAG、问答历史和运行时模型配置

路线图中的能力会优先以可迁移、可回溯和可自托管为约束，不以牺牲数据可控性换取功能数量。项目采用 [GNU AGPL-3.0 双许可模式](/license)。
