# 知识图谱

## 图谱视图

系统以节点表示实体，以连线表示关系。边的粗细反映 `0` 到 `1` 的关系权重，数值越大，表示该关系在当前语境中越重要。

图谱使用静态 ForceAtlas2 布局。孤立节点放置在关系图外围，关系节点还会进行坐标放大和碰撞消解，减少打开页面后的抖动和重叠。

## 搜索与筛选

- 按节点或关系名称检索并高亮结果。
- 查看节点的连接关系和关系说明。
- 从节点或关系跳转至来源文本块。
- 显示关系权重，用于判断知识关联强度。

## 大图谱社区

系统使用 Louvain 社区发现组织大规模图谱。当社区达到分页条件时，会生成跨社区总览与社区详情页。

默认仅为节点数不少于 `20` 的社区生成详情页。修改以下配置后，需要重新生成图谱：

```dotenv
GRAPH_COMMUNITY_MIN_SIZE=1
```

值越小，详情页越多；提高数值可以减少页面数量。

## 原文证据定位

点击节点或关系的“原文查找”，文档面板会定位到对应文本块。高亮会区分：

- 当前查询的实体或关系
- 关系说明与直接证据
- 同一文本块中的其他实体与关系
- 当前命中的完整文本块

这使图谱不只是一张关系图，每个结论都能回到产生它的原文。

## 编辑与历史

图谱支持新增、修改和删除节点或关系。每次操作都可以形成历史快照；还原图谱历史时，系统同步恢复当时的文档快照，避免图谱与原文错位。
