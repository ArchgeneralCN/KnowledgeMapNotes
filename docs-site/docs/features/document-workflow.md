# 文档工作流

## 三种查看模式

| 模式 | 适合场景 |
| --- | --- |
| 预览 | 阅读 Markdown 渲染结果和查看证据高亮 |
| 编辑 | 富文本修改内容，直接观察排版结果 |
| 源码 | 查看或修改原始 Markdown / 文本 |

预览支持缩放、复制和下载。外部链接会使用安全属性打开，Markdown 原始 HTML 被禁用并经过内容清理。

## 草稿与保存

编辑中的未提交内容保存为草稿。切换文件前如有未保存修改，界面会要求先保存或明确放弃，避免快速切换导致内容丢失。

保存文档后，可以从文件列表发起增量更新。系统只处理变化内容，并在完成后自动更新图谱。

## 文档历史

文档每次重要操作都会留下版本记录。你可以查看历史内容并恢复旧版本。图谱历史同时携带文档快照，因此从图谱侧回退时也能恢复一致的原文。

## 证据高亮

原文定位只在预览模式显示完整高亮。可以选择显示全部证据，或只突出当前选中的命中结果，并使用前后按钮在多个来源之间切换。
