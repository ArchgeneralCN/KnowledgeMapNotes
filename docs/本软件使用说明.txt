知识图谱笔记系统（KnowledgeMapNotes）使用说明

本说明面向第一次使用本软件的用户，介绍从 AI 配置、上传文档、生成知识图谱，到查看原文出处、编辑文档、修改图谱、RAG 问答和迁移数据的完整操作流程。

首次启动软件时，系统默认只导入已经处理完成的“本软件使用说明”。即使尚未配置 AI，用户也可以直接打开它，一边阅读说明，一边体验文档预览、知识图谱、社区详情和原文定位。项目的 backend/kmnzips 文件夹中另有“三国志”和“改命记实录(道之光)”两个已完成迁移包，需要时可由用户自行上传导入，它们不会自动出现在文件列表中。


一、软件是做什么的

1. 本软件可以把 TXT、Markdown（MD）和 PDF 文档转换为知识图谱。
2. 软件会自动完成文本分块、实体抽取、关系抽取、关系权重计算和知识融合。
3. 生成的图谱可以搜索、筛选、编辑、查看出处，大图谱会自动生成社区总图和社区详情页。
4. 软件提供 HybridRAG 问答，综合向量检索、实体关系和图谱社区信息回答问题。
5. 节点、关系和 RAG 参考资料都可以跳转到预览模式中的原文文本块，并高亮实体、关系和依据。
6. 文档可以以预览、编辑或源码方式查看，编辑后可以保存草稿并增量更新图谱。
7. 已完成文件可以导出为 .kmn.zip 迁移包，在另一个本软件实例中直接恢复，无需重新调用 AI。


二、支持的文件和使用条件

1. 可直接处理的文档格式：.txt、.md、.pdf。
2. 可直接导入的迁移格式：.kmn.zip。
3. 普通文档建图和 RAG 问答需要可用的 OpenAI 兼容文本模型。
4. PDF 图片内容识别需要后端已配置视觉模型。没有配置时，请关闭“PDF 图片内容识别”。
5. 导入 .kmn.zip 迁移包不会调用 AI，因此没有 AI 配置时也可以导入。
6. 界面提示单个 TXT 文件建议不超过 5 MB。越长的文档分块越多，处理时间和 AI 调用量也越大。
7. 迁移包上传大小不能超过 100 MB。
8. 默认导入的“本软件使用说明”和用户自行导入的已完成迁移包无需 AI；使用这些文件发起新的 RAG 问答时仍需要可用的文本模型。


三、界面快速认识

左侧竖向导航栏包含以下入口：

1. 主页图标：返回文件上传页。
2. 文件图标：打开或收起文件列表。
3. 设置图标：打开 AI 模型、图谱构建和 RAG 问答设置。

主界面分为两种状态：

1. 上传页：用于点击选择文件或拖拽上传。
2. 结果工作区：用于并排查看“文档内容”、“知识图谱”和“RAG 问答”。

页面右下角的主题入口可以切换默认、暗色、蓝色和护眼绿色主题。主题选择会保存在当前浏览器中。

首次启动后的建议操作：

1. 打开文件列表，找到状态为“已完成”的“本软件使用说明”。
2. 双击文件卡片进入结果工作区。
3. 先阅读“文档内容”，再切换到“知识图谱”查看说明内容形成的节点和关系。
4. 在图谱中右键节点或关系，使用“查看节点/查看关系”和“原文查找”，体验证据定位。
5. 需要查看规模更大的实际图谱时，再按第七章或第十八章的步骤自行导入 backend/kmnzips 中的可选迁移包。


四、首次使用：配置 AI

（一）打开设置

1. 点击左侧导航栏底部的“设置”图标。
2. 在“AI 模型设置”中填写主模型信息。

（二）主 AI 字段说明

1. Base URL：OpenAI 兼容服务地址，必须以 http:// 或 https:// 开头，通常包含 /v1。
2. API Key：模型服务密钥。已保存的密钥只会以脱敏形式显示。
3. 模型名称：服务商实际提供的模型标识，例如 qwen-plus。
4. 温度：取值 0 至 2。知识抽取通常建议使用较低温度，以提高结构化输出的稳定性。
5. 思考模式：开启后会向支持该参数的模型请求思考输出。不支持该参数的服务建议关闭。

（三）备用 AI 自动接管

1. 开启“备用 AI 自动接管”后，填写备用 Base URL、备用 API Key 和备用模型名称。
2. 当主 API 请求失败、超时或返回格式无效时，软件会尝试使用备用 AI 继续当前文本块。
3. 开启备用 AI 后，“测试连接”会同时检查主 AI 和备用 AI。

（四）测试并保存

1. 先点击“测试连接”。测试会发送一次最小模型请求，但不会保存当前填写的配置。
2. 看到连接成功和延迟提示后，点击“保存 AI 配置”。
3. 保存后，后续文件抽取和 RAG 问答会使用新配置。
4. 前端设置更新的是当前后端进程中的运行时配置。后端重启后，如果没有在环境配置中预设，可能需要重新填写。
5. 上传普通文档前，软件会再次校验当前 AI 是否可用。


五、图谱构建设置

（一）笔记类型

1. 通用：适合普通笔记、资料、技术文档和综合内容。
2. 故事：适合小说、传记和剧情文本，更关注人物、地点、事件及它们的关系。
3. 自定义：允许分别修改“实体抽取”、“关系抽取”和“知识融合”三阶段提示词。
4. 自定义模式中的“恢复通用提示词”会把三个编辑框恢复为当前版本的通用模板。
5. 笔记类型和自定义提示词会随后续上传一起提交，不会自动重新处理已完成文件。

（二）PDF 图片内容识别

1. 开启后，处理 PDF 时会尝试使用视觉模型生成图片内容描述。
2. 它只影响 PDF，不影响 TXT 和 MD。
3. 图片较多的 PDF 会增加处理时间和视觉模型费用。


六、RAG 问答设置

1. 启用流式输出：回答会逐步显示，处理中可以点击“停止生成”。
2. 关闭流式输出：等待模型完成后一次性显示结果。
3. 携带历史上下文：开启后，新问题会同时参考该文件之前的对话；关闭后，每次问答按独立问题处理。
4. 这些选项会保存在当前浏览器中。


七、上传文档并构建图谱

（一）新文件

1. 确认 AI 配置已测试成功。
2. 在主页上点击上传区，或把文件拖入上传区。
3. 可以一次选择多个文件。
4. 上传时会携带当前笔记类型、PDF 图片识别选项和自定义提示词。
5. 上传成功后文件列表自动打开，任务进入“上传中”或“处理中”。
6. 系统会在后台完成文本转换、分块、实体关系抽取、存储和图谱页面生成。
7. 状态变为“已完成”后，双击文件即可打开结果工作区。

（二）同名文件的增量更新

1. 再次上传同名文件时，前端会询问是否进行增量更新。
2. 点击“增量更新”后，状态变为“增量更新中”。
3. 增量更新会对新旧文本块做差异处理，不是简单覆盖已有图谱。
4. 完成后会自动重新生成图谱主页和社区详情页。
5. 如果同名文件上次处理失败，重新上传会按可用检查点继续或重建，以当前界面状态提示为准。

（三）导入迁移包

1. 将以 .kmn.zip 结尾的迁移包拖入上传区，或点击选择。
2. 界面显示“导入迁移包”，后端会校验包结构、路径和图谱状态。
3. 导入成功后文件直接显示为已完成，不会重新抽取。
4. 如果目标系统已经存在同名文件或同名图谱，导入会被拒绝。请先确认数据内容，再决定是否删除旧数据。
5. 项目随附的可选已完成文件位于 backend/kmnzips，包括“三国志.kmn.zip”和“改命记实录(道之光).kmn.zip”。它们不会自动导入，用户可以按需选择其中一个进行体验。
6. backend/default_examples/本软件使用说明.kmn.zip 由后端在首次启动时自动导入，通常无需用户重复上传。


八、查看处理进度、暂停和恢复

文件可能出现以下状态：

1. 上传中：文件正在上传。
2. 处理中：正在转换和构建图谱。
3. 增量更新中：正在合并新文档内容。
4. 继续处理中：正在从已保存的文本块检查点继续。
5. 暂停中：已收到暂停请求，正在等待当前文本块安全保存。
6. 已暂停：检查点已保存，可以继续处理。
7. 部分完成，可继续：服务中断后仍保留已完成文本块和可用的部分结果。
8. 处理失败，可重试：可查看错误提示，在有检查点时继续。
9. 重新绘制图谱中：只根据当前已保存图谱状态重新生成页面，不会重新调用 AI。
10. 已完成：原文、图谱和 RAG 功能可用。

操作流程：

1. 右键正在处理的文件，选择“暂停处理”。
2. 暂停不会立即强制中断当前 AI 请求；系统会先完成并保存当前文本块。
3. 状态变为“已暂停”后，点击文件卡片中的“继续处理”，或右键选择同名功能。
4. 进度区会显示已完成文本块数、总块数、百分比和预计剩余时间。
5. 处理期间不要反复上传同名文件或同时发起文档更新。


九、文件列表的所有操作

（一）搜索和筛选

1. 点击文件列表顶部的搜索图标，输入文件名的全部或一部分。
2. 点击“筛选”，可按 TXT、PDF、WORD 等列表类型选项和处理状态筛选。这里的 WORD 是文件列表已有记录的筛选项；当前可直接上传并建图的格式仍以第二章列出的 TXT、MD、PDF 为准。
3. 点击“确认”应用筛选，点击“重置”恢复全部文件。
4. 文件超过 10 个时，底部分页器用于切换页面。

（二）文件卡片

1. 单击文件卡片：展开或收起“主要实体”标签。
2. 双击已完成文件：打开文档、图谱和 RAG 结果工作区。
3. 暂停或中断任务有部分图谱时，也可以查看已保留的部分结果。
4. 鼠标移入已完成文件后，可快速清除 RAG 历史或删除文件。
5. 拖动文件列表右边界可调整列表宽度，宽度会保存在当前浏览器。

（三）右键菜单

右键文件后，系统会根据当前状态显示可用功能：

1. 暂停处理：向当前处理任务发送安全暂停请求。
2. 继续处理：从最后完成的文本块检查点恢复。
3. 查看原文与图谱：打开结果工作区。
4. 重新绘制图谱：使用已保存的图谱状态重新生成全部图谱 HTML 页面，不调用 AI。图谱交互功能升级后，旧文件建议执行一次该操作。
5. 应用文档修改并增量更新：只在已保存文档草稿时出现，用于把草稿同步到图谱。
6. 下载原文与图谱迁移包：导出 .kmn.zip。
7. 清除 RAG 历史：删除当前文件的聊天记录，不删除文件和图谱。
8. 删除文件：删除文件、处理状态、图谱、RAG 历史和相关存储数据。该操作需要二次确认，且应视为不可恢复操作。


十、结果工作区的布局与面板

1. 顶部有“原文”、“知识图谱”和“RAG 问答”三个标签。
2. 每个标签右侧的显示/隐藏图标可以收起对应面板。
3. 桌面端可以同时并排多个面板，拖动面板之间的竖向分隔条调整宽度。
4. 当某个面板宽度低于最小值时，系统会自动隐藏面板，避免内容挤压。
5. 手机或较窄窗口中，界面每次重点显示一个活动面板，通过顶部标签切换。


十一、文档内容面板

（一）预览模式

1. 预览模式会按 Markdown 样式显示标题、列表、引用、代码块、表格和链接。
2. 在预览内容区按住 Ctrl（macOS 为 Command）并滚动鼠标滚轮，可在 70% 至 200% 之间放大或缩小。
3. 普通滚轮仍用于上下滚动文档。
4. 切换到另一个文件时，预览缩放恢复为 100%。

（二）源码模式

1. 源码模式显示转换后的纯文本/Markdown 源内容。
2. 它适合检查原始换行、Markdown 标记和复制纯文本。
3. 图谱节点、关系的“原文查找”默认跳转到预览模式，而不是源码模式。

（三）高亮范围“当前/全部”

1. 选择“当前”：重点显示当前查询的节点、关系或依据。
2. 选择“全部”：除当前目标外，同时高亮文本块中其他已识别的实体、关系和关系依据。
3. 文本块背景、当前目标、其他实体/关系和关系依据使用不同的分层高亮。
4. 该设置会保存在当前浏览器中。

（四）出处定位器

1. 从图谱节点、关系或 RAG 参考资料发起定位后，文档顶部会显示“节点出处”或“关系出处”。
2. 如果同一目标有多个文本块，会显示多个出处卡片。
3. 点击出处卡片，或使用“上一个/下一个”，预览区会滚动到对应文本块。
4. 如果系统找不到完整文本块，会尝试按当前实体、关系或依据词回退定位。

（五）复制和下载

1. 点击文档工具栏的复制图标，将完整纯文本复制到剪贴板。
2. 点击下载图标，将当前文档下载为 Markdown 文件。


十二、编辑文档、版本还原和增量同步

（一）编辑文档

1. 在文档工具栏切换到“编辑”。
2. 可使用粗体、斜体、下划线、项目列表、引用和清除格式工具。
3. 文档内容发生改动后，“保存草稿”按钮变为可用。
4. 点击“保存草稿”只保存文档草稿和文档历史，不会立即改变图谱。
5. 保存后文档标题区会显示“有未应用修改”。
6. 在编辑未保存时切换到其他文件，系统会要求选择“保存并切换”或“放弃修改”。

（二）文档历史

1. 有文档历史时，编辑工具区会显示“还原版本”。
2. 选择一个版本，确认还原后，该版本内容会成为新的文档草稿。
3. 还原操作也会创建新的历史版本，不会直接删除后续历史。
4. 文档还原后仍需要执行增量更新，才会同步到图谱。

（三）将草稿同步到图谱

1. 保存草稿后，打开文件列表。
2. 右键对应文件，选择“应用文档修改并增量更新”。
3. 确认后文件进入“增量更新中”。系统会对修改后的文本块重新抽取并更新图谱。
4. 完成后草稿成为当前正式文档，图谱页面自动重新绘制。
5. 该步骤会调用 AI，请确认当前 AI 配置可用。


十三、知识图谱的基本操作

（一）画布操作

1. 滚动鼠标滚轮可缩放图谱画布。
2. 按住画布空白处拖动可平移视图。
3. 节点可以自由拖动。大图谱初始使用服务端静态力导向坐标，打开后不会持续弹动。
4. 点击关系时会显示关系标签，移入节点或关系可查看提示。
5. 点击页面上方的“沉浸模式”可折叠图谱浮动面板，再次点击退出。

（二）实体与关系搜索

1. 左上角“实体与关系”面板可输入实体名或关系名。
2. 结果会显示类型、名称和连接数/权重。
3. 点击实体结果，图谱会选中并聚焦该节点，同时请求原文出处。
4. 点击关系结果，图谱会选中关系并适应起点和终点，同时请求原文出处。

（三）图谱控制

1. 显示标签：显示全部关系标签。
2. 隐藏标签：隐藏未选中关系的标签，减少画面干扰。
3. 折叠 Hub：对高连接节点隐藏部分次要关系。
4. 节点聚焦：先选中一个或多个节点，再点击该按钮，只保留选中节点和相邻节点。再次点击可退出。
5. 适应画布：把当前可见图谱缩放到可见范围。
6. 重置：清除类型、权重、搜索和聚焦状态，恢复默认图谱视图。

（四）筛选与类型聚焦

1. “最小关系权重”只显示不低于当前阈值的关系。
2. “Hub 关系透明度”调整高连接节点关系的显示强度。
3. “实体类型”支持多选，可以只显示指定类型节点。
4. “全选”勾选全部类型，“清除”取消类型限制。


十四、查看节点和关系的原文出处

（一）节点出处

1. 在图谱中右键节点，选择“查看节点”。
2. 节点详情会显示节点名称、节点类型、连接数和出处文本块。
3. 点击“原文查找”后，文档面板会打开并切换到预览模式。
4. 系统会展示所有可定位的文本块，并高亮当前节点。

（二）关系出处

1. 在图谱中右键关系，选择“查看关系”。
2. 关系详情会显示起点、终点、关系名称、出处依据/关系说明、出处文本块、得分/权重、关系来源和关系 ID。
3. 点击“原文查找”，文档预览会跳转到对应文本块，并分层高亮起点、终点、关系和依据。
4. 手工新增的关系如果没有原始文本块，会显示无可定位出处。


十五、编辑图谱和历史还原

（一）右键图谱操作

1. 右键画布空白处：可以“新增节点”或打开“历史记录与还原”。
2. 右键节点：可以查看节点、编辑节点、从此节点新增关系、删除节点、打开历史。
3. 右键关系：可以查看关系、编辑关系、删除关系、打开历史。

（二）新增和编辑

1. 新增节点时填写节点名称和节点类型。节点名称不能为空，且不能与现有节点重名。
2. 编辑节点可以修改节点名称和类型。
3. 从节点新增关系时，填写终点节点名称、关系名称和关系说明。默认权重为 0.5。
4. 编辑关系可以修改起点、终点、关系名称、关系说明和 0 至 1 的得分/权重。
5. 保存图谱修改后页面会重新加载，图谱页面会根据最新状态重建。
6. 删除节点会同时移除与它相连的关系，请在确认弹窗中仔细检查。

（三）图谱历史与联合还原

1. 每次节点、关系或文档相关操作都会生成历史记录。
2. 选择“历史记录与还原”后，输入要还原的版本号。
3. 确认还原后，系统会创建一个新的历史版本，而不是删除原有历史。
4. 图谱历史包含联合文档快照。还原图谱时，文档也会恢复到对应快照，前端会同步刷新文档和引用数据。
5. 还原前建议先导出迁移包或确认历史列表，避免误选版本。


十六、大图谱社区总图和社区详情

（一）社区总图

1. 当 Louvain 检测到多个社区，且社区规模达到分页条件时，图谱主页显示社区总图。
2. 每个社区使用社区内连接度最高的实体作为社区主节点。
3. 总图中的节点名、节点 ID、实体类型和节点出处都来自该社区主节点。
4. 跨社区关系的可见起点和终点为两个社区的主节点实体名，不使用社区编号。
5. 跨社区关系会携带被选中原始关系的出处文本块、上下文、证据起终点和来源，用于原文定位和高亮。

（二）“社区详情”控制面板

1. 社区总图右下角显示“社区详情”列表。
2. 每个社区条目显示社区主节点实体名、节点数和主节点类型。
3. 搜索框可搜索社区编号名（例如“社区10”）、社区主节点名和社区内部任意节点名。
4. 搜索会忽略常见空格、标点和全半角差异，并支持非连续字符匹配。
5. 主节点或社区名命中的社区优先排在前面，其次是内部节点命中的社区；命中条目会高亮，其他社区保留在后面。
6. 实体类型下拉框可按社区主节点类型筛选。
7. 点击社区名进入社区详情页，详情页只显示该社区内的节点和关系。
8. 点击“查看原文文本块”，可定位社区主节点的原文出处。
9. 社区详情页右下角的“返回社区列表”用于返回总图。


十七、RAG 问答的具体操作

1. 先打开一个已完成文件的结果工作区。
2. 切换到“RAG 问答”面板。
3. 在输入框中输入问题，点击“发送”；也可使用 Ctrl+Enter 发送。
4. 流式输出开启时，回答会实时增长。需要中止时点击“停止生成”。
5. 聊天区默认跟随最新回答。用户主动向上滚动后会停止自动跟随，可用底部箭头回到最新消息。
6. 开启“携带历史上下文”后，可以继续追问，例如“他还做了什么？”。
7. AI 回答和“参考资料”中的可识别引用可以点击。点击后系统会尝试在图谱中选中节点/关系，并在文档预览中定位原文。
8. 每个文件的聊天状态相互独立。切换文件时，界面会加载该文件的聊天历史。
9. 要清理聊天，在文件列表中使用“清除 RAG 历史”。该操作不会删除文档或图谱。


十八、迁移、备份和恢复

（一）导出

1. 文件状态必须为“已完成”。
2. 右键文件，选择“下载原文与图谱迁移包”。
3. 生成的 .kmn.zip 包含原始文件、源文本、处理后文本、图谱页面、可恢复图谱状态、处理状态和 RAG 历史。
4. 迁移包是用于在本软件实例之间迁移的完整包，不要仅保留其中某个 HTML 代替备份。

（二）导入

1. 在新系统上打开上传页。
2. 点击上传区选择 .kmn.zip，或把迁移包直接拖入上传区。
3. 若要体验项目附带的完整图谱，可选择 backend/kmnzips/三国志.kmn.zip 或 backend/kmnzips/改命记实录(道之光).kmn.zip。
4. 等待界面显示“已导入”。迁移包较大时，请等待上传和校验完成，不要重复提交。
5. 打开文件列表，双击恢复后的文件检查原文、图谱、社区详情和已有 RAG 历史。
6. 导入不会调用 AI，但与该文件相关的新 RAG 问题仍需要可用 AI。
7. 系统已经默认提供“本软件使用说明”时，不要再次导入同名默认包，否则会因同名数据被拒绝。


十九、推荐的日常工作流程

流程 A：第一次将资料转为图谱

1. 打开设置，填写主 AI。
2. 点击“测试连接”，成功后保存。
3. 选择笔记类型和 PDF 图片识别选项。
4. 上传文档，在文件列表观察进度。
5. 完成后双击文件，检查文档、图谱和主要实体。
6. 右键重要节点和关系，使用“原文查找”核对抽取质量。
7. 在 RAG 面板提问，点击参考资料复核原文。
8. 完成后导出 .kmn.zip 作为迁移备份。

流程 B：修正文档并同步图谱

1. 打开文档“编辑”模式。
2. 修改内容并点击“保存草稿”。
3. 先在预览中检查格式和内容。
4. 右键文件，选择“应用文档修改并增量更新”。
5. 等待增量更新完成，再检查图谱和原文出处。

流程 C：手工修正图谱

1. 在图谱中右键节点或关系。
2. 修改名称、类型、说明或权重，然后保存。
3. 删除前先用“查看节点/关系”和“原文查找”核对。
4. 修改后重新查看搜索、类型筛选和 RAG 引用是否符合预期。
5. 需要回退时，打开“历史记录与还原”并选择版本。

流程 D：中断后继续长文档

1. 检查文件卡片的已完成块数和是否显示“可继续”。
2. 如果任务仍在运行，右键选择“暂停处理”，等待“已暂停”。
3. 重新确认 AI 配置可用。
4. 点击“继续处理”，从检查点恢复。

流程 E：不配置 AI，先体验已完成图谱

1. 首次启动后，在文件列表双击默认的“本软件使用说明”。
2. 查看文档预览、知识图谱、社区详情，并用“原文查找”核对出处。
3. 需要更大规模的示例时，回到上传页。
4. 从 backend/kmnzips 中选择“三国志.kmn.zip”或“改命记实录(道之光).kmn.zip”上传。
5. 导入完成后双击文件查看。此过程不调用 AI；只有发起新的 RAG 问答时才需要配置 AI。


二十、安全、数据和费用注意事项

1. 上传普通文档、应用文档增量更新和 RAG 问答都可能产生 AI 调用费用。
2. “重新绘制图谱”、查看图谱、导入迁移包不会重新调用 AI。
3. 上传敏感文档前，请确认 AI 服务商、服务地址和数据合规要求。
4. API Key 不要出现在文档、截图、公开日志或迁移包名称中。
5. 删除文件会删除其相关的图谱和聊天数据。重要数据请先导出 .kmn.zip。
6. 清除 RAG 历史只影响聊天历史，不影响文档和图谱。
7. 图谱手工修改会进入历史，但仍建议在大量修改前导出备份。
8. 浏览器本地存储包含主题、界面宽度、部分设置和聊天缓存。清理浏览器数据可能会恢复界面默认值，但不会自动删除后端保存的图谱文件。


二十一、常见问题和处理方法

1. 提示“请先在前端完成 AI 配置”
   处理：打开设置，检查 Base URL、API Key 和模型名称，先测试连接，再保存。

2. AI 连接测试超时或失败
   处理：检查网络、地址是否包含正确的 /v1、密钥权限、模型名称和服务商额度。不支持思考参数时关闭思考模式。

3. 上传后长时间处理
   处理：查看文本块进度和预计时间。长文档、高质量提示词和 PDF 图片识别都会延长时间。需要停止时使用安全暂停。

4. 暂停后没有立即变成“已暂停”
   说明：软件需要等待当前文本块完成并保存，这是为了避免损坏检查点。

5. 图谱一直显示加载中
   处理：先确认文件是否已完成，然后刷新页面。对旧图谱可右键文件执行“重新绘制图谱”。

6. 社区详情列表无法搜索内部节点
   处理：对旧文件执行“重新绘制图谱”。新图谱页面才会包含社区内部节点搜索索引。

7. 点击“原文查找”没有定位结果
   说明：手工新增实体/关系可能没有文本块；旧图谱也可能没有完整证据字段。先尝试重新绘制，再检查节点/关系详情中的出处文本块。

8. 图谱中出现不正确节点或关系
   处理：先用原文查找核对，然后右键编辑或删除。如果需要回退，使用图谱历史还原。

9. 保存文档后图谱没有变化
   说明：“保存草稿”不会立即更新图谱。请右键文件，执行“应用文档修改并增量更新”。

10. RAG 回答不连贯
    处理：在设置中开启“携带历史上下文”。如果需要全新会话，则清除该文件的 RAG 历史。

11. 迁移包无法导入
    处理：确认文件名以 .kmn.zip 结尾、包未损坏、不超过 100 MB，并且目标系统不存在同名文件或图谱。

12. 复制文档失败
    处理：浏览器可能拒绝剪贴板权限。可切换到源码模式手动选择，或使用“下载 Markdown”。


二十二、快捷操作汇总

1. Ctrl+Enter：在 RAG 输入框中发送问题。
2. Ctrl+滚轮（macOS 为 Command+滚轮）：在文档预览模式中缩放。
3. 双击文件卡片：打开结果工作区。
4. 右键文件卡片：打开文件操作菜单。
5. 右键图谱节点/关系/空白处：打开图谱查看、编辑、删除或历史菜单。
6. 拖动文件列表边界：调整文件列表宽度。
7. 拖动结果面板分隔条：调整文档、图谱和 RAG 面板宽度。


二十三、新用户建议

1. 首次打开软件时，先双击默认的“本软件使用说明”，用它熟悉文档、社区图谱和原文定位。查看内容不会调用文本 AI，但新的 RAG 问题会调用 AI。
2. “三国志”和“改命记实录(道之光)”不会自动导入；需要实际内容示例时，从 backend/kmnzips 文件夹中选择对应 .kmn.zip 上传。
3. 第一份自己的文档建议使用较短的 TXT 或 MD，先验证 AI 配置和抽取效果。
4. 建图后不要只看节点数量，应抽查多个节点和关系的原文出处。
5. 对非常重要的知识库，建议在文档增量更新、批量图谱编辑或删除操作前导出迁移包。
6. 当软件升级图谱交互功能后，已有图谱可以通过“重新绘制图谱”获得新页面能力，无需重新做 AI 抽取。
