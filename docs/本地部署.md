# KnowledgeMapNotes 本地一键部署

本指南适用于 Windows、Linux 和 macOS。一键启动器会准备 Python 环境、下载 ModelScope 模型、构建前端，再由 FastAPI 在同一个端口提供完整 Web 应用。

## 环境要求

- Python 3.10 或更高版本。
- Node.js 18 或更高版本，仅在首次或前端变更后构建时使用。
- 首次启动需要网络连接，用于安装依赖并从 ModelScope 下载模型。
- 预留至少 2 GB 模型空间，另需 Python 依赖和运行数据空间。

## 启动方式

Windows 可双击项目根目录的 `start.bat`，或在 CMD/PowerShell 中执行：

```bat
start.bat
```

Linux 和 macOS 在项目根目录执行：

```bash
./start.sh
```

三个平台也都可直接运行：

```bash
python start.py
```

启动完成后，终端会显示实际访问地址：

```text
[start] KnowledgeMapNotes is starting at http://127.0.0.1:8000
```

浏览器访问该地址即可。服务运行期间不要关闭终端，按 `Ctrl+C` 可安全停止。

## 启动器做了什么

首次运行会依次执行：

1. 在项目根目录创建 `.venv` Python 虚拟环境。
2. 安装后端依赖、ModelScope 和 PyTorch。
3. 下载 `BAAI/bge-base-zh` 到 `models/bge-base-zh`。
4. 下载 `BAAI/bge-reranker-base` 到 `models/bge-reranker-base`。
5. 将两个模型的本地绝对路径写入 `backend/.env`。
6. 执行 `npm ci` 并构建前端。
7. 加载本地模型并启动 FastAPI。

启动器会记录依赖和前端源码的指纹。后续运行时，未变更的依赖、已完整下载的模型和最新前端构建都会跳过。

## 端口选择

默认仅在本机监听 `127.0.0.1:8000`。可在 `backend/.env` 中修改首选地址和端口：

```dotenv
HOST=127.0.0.1
PORT=8000
```

如果首选端口已被其他进程占用，启动器会自动使用下一个可用端口。例如 `8000` 被占用时：

```text
[start] Port 8000 is already in use; using port 8001.
[start] KnowledgeMapNotes is starting at http://127.0.0.1:8001
```

自动选择的端口仅对当次启动有效，不会修改 `.env`。下次启动仍会先尝试 `PORT` 指定的端口。

如需从局域网其他设备访问，可设置 `HOST=0.0.0.0`，再通过主机的局域网 IP 和终端打印的端口访问。此时还需检查系统防火墙，且不应将未带鉴权的服务直接暴露到公网。

## 配置文件

`backend/.env` 保存本地运行配置。启动器只会自动更新以下三项：

```dotenv
IS_USE_LOCAL=True
EMBEDDINGS_PATH="<项目绝对路径>/models/bge-base-zh"
RERANK_MODEL="<项目绝对路径>/models/bge-reranker-base"
```

API Key、文本模型地址、分块参数等其他配置会原样保留。如果 `.env` 不存在，启动器先复制 `backend/.env.example`，再写入实际模型路径。

## 目录说明

| 路径 | 用途 | 是否可重新生成 |
| --- | --- | --- |
| `.venv/` | Python 虚拟环境和后端依赖 | 是 |
| `models/` | ModelScope 下载的嵌入和重排模型 | 是，需重新下载 |
| `frontend/node_modules/` | 前端依赖 | 是 |
| `frontend/dist/` | 由 FastAPI 托管的前端构建产物 | 是 |
| `backend/.env` | 本地配置和密钥 | 否，应自行备份 |
| `backend/uploads/` | 上传的原始文件 | 否 |
| `backend/txt_files/` | 处理后的文本和编辑内容 | 否 |
| `backend/results/` | 图谱结果 | 否 |
| `backend/chroma_data/` | RAG 向量数据 | 否 |

## 更新项目

获取新代码后，仍使用原启动命令。当 `backend/requirements.txt` 发生变化时，启动器会自动更新 Python 依赖；当前端源码或依赖发生变化时，会自动重新构建。

## 常见问题

### Python 或 Node.js 未找到

确认 `python --version` 或 `python3 --version` 不低于 3.10，`node --version` 不低于 18，并确保命令已加入系统 `PATH`。

### ModelScope 下载中断

检查网络后重新运行启动脚本。ModelScope 会继续准备未完整的模型，只有在配置和 safetensors 权重都存在后才会被启动器标记为完成。

### 启动地址不是 8000

这表示首选端口已被占用。直接使用终端最后打印的 URL，或停止占用首选端口的程序后重新启动。

### `.venv` 已损坏

如果启动器提示现有虚拟环境无法使用，先备份或重命名 `.venv`，再运行启动脚本创建新环境。此操作不会影响 `backend/` 中的文档、图谱和向量数据。
