# HybridRAG 问答

HybridRAG 不只使用向量相似度。系统会识别问题中的实体，结合关系权重与图谱社区补充上下文，再把来源文本提交给模型。

## 问答模式

- **流式输出**：回答逐步显示，处理中可以停止生成。
- **普通输出**：模型完成后一次性显示结果。
- **历史上下文**：把当前文件的对话历史带入新问题。

文件之间的聊天状态相互隔离。删除文件或清理 RAG 历史时，前端也会同步清理对应的浏览器缓存。

## 检索参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `top_k` | `1` | 向量召回数量 |
| `weight_threshold` | `0.3` | 参与问答的最低关系权重 |
| `max_relations` | `20` | 最多使用的关系数量 |

提高 `top_k` 和 `max_relations` 能提供更多上下文，但也会增加输入长度。关系稀疏时可适当降低 `weight_threshold`。

## 来源回溯

回答附带的参考资料可以跳转至文档内容面板。系统会定位具体文本块并突出问题相关的实体、关系和说明，方便验证回答依据。

## 请求示例

```json
{
  "request": "这篇文档的核心观点是什么？",
  "filename": "example.pdf",
  "flow": true,
  "top_k": 3,
  "weight_threshold": 0.3,
  "max_relations": 20,
  "messages": [],
  "session_id": null
}
```
