# 创建第一张图谱

## 选择适合的文档

第一次使用建议选择结构清晰、篇幅适中的 Markdown 或 TXT 文件。单个 TXT 建议不超过 5 MB；文档越长，分块越多，模型调用量也越大。

支持的输入：

| 类型 | 用途 |
| --- | --- |
| `.txt` | 纯文本资料、聊天记录、文章 |
| `.md` | 带标题层级和代码块的笔记 |
| `.pdf` | 论文、报告和扫描资料 |
| `.kmn.zip` | 从另一实例完整恢复，无需重新调用 AI |

## 上传并观察进度

把文件拖入上传区。文件卡片会显示当前阶段、已完成分块、百分比、单块耗时与预计剩余时间。

处理中可以请求暂停。系统会在当前文本块结束后写入检查点；再次点击恢复，会从检查点继续而不是从头开始。

## 打开结果工作区

处理完成后双击文件卡片。工作区包含三个可调整宽度的面板：

1. **文档内容**：预览原文、编辑内容与查看源码。
2. **知识图谱**：探索节点、关系和社区。
3. **RAG 问答**：围绕当前文档提问并查看依据。

面板可以隐藏、重新打开或拖动分隔条调整宽度。窄屏下会自动切换为更适合单列阅读的布局。

## 从图谱回到原文

1. 在图谱中选中节点或关系。
2. 打开对应的详情或上下文菜单。
3. 选择“原文查找”。
4. 文档面板会跳转到来源文本块，并用不同层级标出当前实体、关系、关系说明和其他证据。

当一个实体在多个位置出现时，可以用上一个/下一个结果逐条查看；“全部 / 当前”控制高亮范围。

## 继续探索

在 RAG 面板输入“这篇文档的核心观点是什么？”或针对某个节点追问。点击回答中的参考资料，可以跳回对应的原文证据。
